# 🏥 Hospital Emergency Room Dashboard | Excel

## 📌 Project Overview

The **Hospital Emergency Room Dashboard** is a data analytics project developed using Microsoft Excel to analyze emergency room patient data and monitor key hospital performance indicators.

The dashboard provides insights into patient visits, waiting times, admission status, gender distribution, age groups, department referrals, and patient satisfaction. It helps present complex data in a clear, interactive, and visually appealing format to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze the number of patients visiting the emergency room.
- Monitor patient waiting times and timeliness of medical attention.
- Compare admitted and non-admitted patients.
- Understand patient demographics by age group and gender.
- Identify the most frequently referred departments.
- Track average waiting time and patient satisfaction trends.
- Present key performance indicators through an interactive dashboard.

## 📊 Dashboard Features

### 1. Total Number of Patients
Displays the total number of patients visiting the emergency room using KPI cards. Area sparklines show daily patient trends and help identify busy periods.

### 2. Average Wait Time
Calculates the average time patients wait to receive medical attention. Daily area sparklines help track changes in waiting time.

### 3. Patient Satisfaction Score
Displays the average patient satisfaction score and uses sparklines to monitor daily trends in service quality.

### 4. Timeliness Analysis
Shows the percentage of patients attended to within 30 minutes compared with patients who experienced delays.

### 5. Patient Admission Status
Compares the number and percentage of admitted and non-admitted patients.

### 6. Gender Analysis
Visualizes the distribution of patients by gender using a doughnut chart.

### 7. Patient Age Distribution
Groups patients into different age categories and displays their distribution using a column chart.

### 8. Department Referrals
Highlights the number of patients referred to different departments, helping identify the departments receiving the most referrals.

### 9. Interactive Filters
Includes year and month filters to explore patient data for selected reporting periods.
